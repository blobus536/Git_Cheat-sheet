# Всякие команды для Git

**git --version** для проверки наличия Git и его версии

**git init** создаёт скрытую папку .git в выбранной папке

Команда **git status** Показывает текущее состояние гита, есть  ли изменения, которые нужно закоммитить 

**git add** добавляет содержимое рабочего каталога  в индекс (staging area) для последующего коммита.

**git commit** берёт все данные, добавленные в индекс с помощью git add, и сохраняет их слепок во внутренней базе данных, а затем сдвигает указатель текущей ветки на этот слепок.

**git log** показывает количество сохранений

**git checkout** переключение между версиями

**git diff** Показывает разницу между текущим файлом и сохранённым
