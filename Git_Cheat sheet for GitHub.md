# Всякие команды для Git

**git --version** для проверки наличия Git и его версии

**git init** создаёт скрытую папку .git в выбранной папке

Команда **git status** Показывает текущее состояние гита, есть  ли изменения, которые нужно закоммитить 

**git add** добавляет содержимое рабочего каталога  в индекс (staging area) для последующего коммита.

**git commit** берёт все данные, добавленные в индекс с помощью git add, и сохраняет их слепок во внутренней базе данных, а затем сдвигает указатель текущей ветки на этот слепок.

**git log** показывает количество сохранений

**git checkout** переключение между версиями

**git diff** Показывает разницу между текущим файлом и сохранённым

**git diff --staged** Просмотр индексированных изменений

**git switch** <имя_ветки>

**git branch** просмотр всех веток

**git branch <имя_ветки>*** Создание новой ветки


**git clone <url>** Клонирование существующего репозитория

**git checkout** -- <файл>
 или
**git restore** <файл>

# Работа с удаленным репозиторием (Remote)

**git remote add origin**<url>— привязка локального репозитория к удаленному (например, на GitHub).

**git push -u origin** <ветка> — отправка изменений на удаленный сервер (флаг -u нужен только при первой отправке новой ветки). 

**git pull** — получение изменений с удаленного репозитория и их автоматическое слияние с текущей веткой.

**git fetch** — получение изменений с удаленного репозитория, но без слияния (безопасный просмотр).

# Слияние и ветвление (Merge & Branch)

**git merge** <имя_ветки> — слияние указанной ветки с текущей.

 **git branch -d** <имя_ветки> — удаление локальной ветки (после слияния).
 
**git push origin** --delete <имя_ветки> — удаление ветки на удаленном репозитории.

# Исправление ошибок и откаты (Undo)

 **git reset --soft HEAD~1** — отменяет последний коммит, но оставляет изменения в файлах (в индексе).
 
 **git reset --hard HEAD~1** — опасная команда, полностью удаляет последний коммит и все изменения в файлах.
 
**git commit --amend** — изменить сообщение последнего коммита или добавить забытые файлы в него.

**git restore --staged** <файл> — убрать файл из индекса (отмена git add), не удаляя изменения в самом файле.

# Продвинутая работа с историей

**git stash** — временно «прячет» незакоммиченные изменения, чтобы можно было переключиться на другую ветку.

**git stash pop** — возвращает спрятанные изменения обратно.

**git cherry-pick** <хэш_коммита> — переносит конкретный коммит из другой ветки в текущую.

**git log** --oneline --graph — красивый и компактный просмотр истории коммитов в виде графа.

**Rebase** — инструмент, который позволяет формировать линейную историю целевой ветки. Одна ветка объединяется с другой, а коммиты при этом сохраняются.

# Полезные мелочи

· git config --global user.name "Ваше Имя" — настройка имени пользователя (делается один раз).
· git config --global user.email "email@example.com" — настройка почты.
· git remote -v — просмотр списка подключенных удаленных репозиториев
